# Shayan Yo — Link Bio

A modern and responsive Link Bio website designed for **Shayan Yo**, providing quick access to official social media profiles, music platforms, and other important links.

## ✨ Features

- 🎨 Modern and minimal dark UI
- 📱 Fully responsive design
- ⚡ Lightweight and fast
- 🎵 Music platform links
- ▶️ YouTube & YouTube Music submenu
- ✨ Animated lightning background
- 🔗 Easy-to-manage links
- 🌐 Optimized for desktop and mobile

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
